Anime08 website
---------------
1. Unzip this folder.
2. Double-click index.html to open it in your browser.
3. To put it online, upload index.html to a free host such as Netlify Drop (app.netlify.com/drop), GitHub Pages or Vercel.

Edit the text, colors and links by opening index.html in any text editor (Notepad, VS Code).
Note: the fonts need internet to load.
